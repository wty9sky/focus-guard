# 专注守门员 · 使用文档

> 拦抖音、短剧这类一刷就停不下来的网站。想提前打开？先看清代价，再干等 10 秒。
> 忍住不看就每分钟加分，分攒够了能换自己定的奖励。数据只存在本地，不上传。

- **版本**：1.0.0（Manifest V3）
- **适用**：Chrome / Edge 等 Chromium 内核浏览器，最低版本 109
- **安装方式**：本地加载（未上架商店）

---

## 1. 安装

```bash
npm install
npm run build      # 产物在 dist/
```

然后在浏览器里：

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选中项目里的 **`dist`** 目录
4. 建议把它固定到工具栏，方便随时开关

> 改过源码后要重新 `npm run build`，再回扩展页点一次「重新加载」，新代码才会生效。

---

## 2. 五分钟上手

1. **黑名单** → 输入 `douyin.com` 回车（或直接点下方的常见站点快捷芯片）
2. **状态** → 选一个时长（如 25 分钟），打开「一键屏蔽」开关
3. 去访问刚才那个站点 → 应该看到白屏警告页和倒计时
4. **规则** → 按自己的作息调每日目标和冷却时长（可选）

做到第 3 步，核心链路就跑通了。定时屏蔽和奖励兑换可以先放着，等习惯之后再配。

## 3. 界面说明

弹窗共 5 个标签页，下面按使用频率讲。

### 3.1 状态

整个插件的总控制台。

| 区域 | 作用 |
| --- | --- |
| 圆环倒计时 | 当前还剩多久解除；未屏蔽时显示「当前未屏蔽」 |
| 来源标签 | 为什么被屏蔽：`手动屏蔽` / 定时规则名 / `通行证豁免` / `冷却暂停` |
| 一键屏蔽 | 开关 + 快捷时长：25 / 45 / 90 / 120 / 240 / 480 分钟，点开即刻生效 |
| 今日专注 | 今日已专注分钟数、当前积分、连续达标天数、目标进度条 |
| 解除屏蔽 | 「解除屏蔽（有代价）」和「通行证 ×N」两个入口 |
| 时钟保护 | 只有检测到改系统时间才会出现，显示补回了多少时长 |

### 3.2 黑名单

- **匹配规则**：按域名，**自动包含所有子域名**。填 `bilibili.com` 就会同时命中 `www.bilibili.com`、`m.bilibili.com`、`live.bilibili.com`。
- **不需要带** `https://`、路径或端口，直接填域名即可；带了也会自动清理。
- 黑名单只在「一键屏蔽开启」或「定时屏蔽生效中」才会拦截，平时不影响正常浏览。

### 3.3 定时

按「星期 + 时间段」自动屏蔽，到点自己生效。

- 支持**跨零点**：`23:00 - 02:00` 是合法的，会正确跨天。
- 可设置多条规则，也可以单独关闭某一条（开关只停用，不删除）。
- 点「编辑」可改现有规则，改完记得保存。
- **定时屏蔽不能被永久解除**：提前解除只会「暂停」一个冷却周期，到点自动恢复。这是刻意设计的，避免一键抹掉长期规则。

### 3.4 奖励

积分、连胜、徽章和兑换都在这里。

| 项目 | 说明 |
| --- | --- |
| 可用积分 | 屏蔽赚来的分，兑换时消耗 |
| 连续达标 | 当日专注满「每日目标」记 1 天；断一天清零 |
| 最长连胜 | 历史最好成绩 |
| 徽章 | 9 枚，达成后自动发放一次性积分 |
| 积分商店 | 自由通行证 200 分、连胜护盾 400 分（最多持有 3 个） |
| 添加现实奖励 | 自己写名称和价格，如「看一集剧」300 分、「一杯奶茶」200 分 |

**建议一定要配现实奖励**。积分只是数字，能换到真实的放松才有意义。

### 3.5 规则

参数配置和数据管理。

| 参数 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 每日达标目标 | 120 分钟 | 10–720 | 当天专注满这个时长算打卡成功 |
| 提前解除基础冷却 | 15 分钟 | 1–120 | 第 n 次解除按 2^(n-1) 递增，上限 240 分钟 |
| 严格模式 | 关 | — | 屏蔽期间隐藏「提前解除」，只能用通行证 |
| 承诺语 | 空 | 40 字 | 填了之后，解除时必须逐字输入这一句 |

底部「数据」区域可以导出 JSON 备份、导入恢复、重置统计（重置会保留黑名单、定时规则和参数，只清积分与记录）。

## 4. 拦截页怎么用

尝试访问被屏蔽站点时，页面会被替换成一个白屏警告页。

- **剩余时间**：大字倒计时 + 预计解除时间（精确到分钟）
- **提前解除（有代价）**：点开后会列出完整代价清单——扣多少分、冷却多久、连胜是否清零、当日的达标是否作废，并要求等满 **10 秒冷静倒计时**；填了承诺语还要逐字输入
- **使用自由通行证解除**：有通行证时显示，豁免 30 分钟且完全免罚，不扣分、不清连胜、不进冷却
- **离开，去做正事**：返回上一页
- **误拦自动放行**：如果屏蔽其实已经结束、只是规则还没清理，页面会显示「屏蔽已解除」并在约 2 秒后自动把你送回原站点，也可以点「留在本页」取消

## 5. 机制细节

### 5.1 怎么赚分

| 来源 | 数值 |
| --- | --- |
| 屏蔽期间每分钟 | +1 分（定额） |
| 有定时规则在生效 | ×1.2 |
| 严格模式开启 | ×1.5 |
| 当日达标 | 结算时一次性 `目标分钟 × 0.6` 分 |
| 徽章 | 见下表，一次性发放 |

**徽章一览**

| 徽章 | 条件 | 奖励分 |
| --- | --- | --- |
| 🌱 首次屏蔽 | 完成第一次有效屏蔽 | 10 |
| 🍀 初入佳境 | 累计专注 10 小时 | 50 |
| 🔥 心无旁骛 | 累计专注 50 小时 | 200 |
| ⚓ 定海神针 | 累计专注 100 小时 | 400 |
| 🗡️ 十年磨剑 | 累计专注 500 小时 | 2000 |
| 🥉 三日之约 | 连续达标 3 天 | 80 |
| 🥈 一周自律 | 连续达标 7 天 | 200 |
| 🥇 半月不辍 | 连续达标 14 天 | 500 |
| 💎 一月之墙 | 连续达标 30 天 | 1200 |

积分按整分钟结算；屏蔽结束时空出来的零头（≥30 秒）会补记 1 分钟，不会白等。

### 5.2 提前解除要付什么

| 代价 | 规则 |
| --- | --- |
| 扣积分 | `min(当前积分, 本次屏蔽已获积分 × 50% + 30 × 档位)`，档位 = 24 小时内第几次，最多按 3 档算 |
| 进冷却 | `min(基础冷却 × 2^(n-1), 240 分钟)`，默认基础 15 → 15 / 30 / 60 / 120 / 240 |
| 冷却期内 | 无法再次解除，按钮禁用，显示剩余时间 |
| 连胜 | 有护盾则消耗 1 个保住连胜；没有则立刻清零 |
| 当日达标 | 直接记为失败，当天不再计达标（第二天自动复原） |
| 定时屏蔽 | 只是暂停一个冷却周期，到点自动恢复 |

**为什么惩罚不做「时长翻倍」**：单向加码容易引发破罐破摔——「今天已经毁了，不如彻底放开」。所以失败只影响当天。

**为什么永远留一个通行证**：完全没有逃生口，结局一定是卸载。留一个合法出口，反而更容易长期用下去。

### 5.3 防作弊

- **改系统时间无效**：时间前进超过 10 分钟会被判为跳变，按真实流逝顺延剩余屏蔽时长；回退超过 30 秒会被判为回拨，自动补回。单次最多纠正 4 小时，避免异常数据把屏蔽无限拉长。状态页会出现「时钟保护」卡片提示。
- **但关掉/卸载扩展是拦不住的**，这是所有浏览器扩展的共同边界。

## 6. 推荐配置

| 人群 | 每日目标 | 基础冷却 | 严格模式 | 承诺语 |
| --- | --- | --- | --- | --- |
| 轻度起步 | 60 分钟 | 10 分钟 | 关 | 不必填 |
| 中度（默认） | 120 分钟 | 15 分钟 | 关 | 建议填 |
| 备考 / 冲刺 | 240 分钟 | 30 分钟 | 开 | 建议填 |

**针对短剧沉迷的一份配置**

```
黑名单：douyin.com、bilibili.com、xiaohongshu.com、weibo.com
定时：  工作日 20:00–23:30，周末 12:00–23:30 全部生效
严格模式：开
承诺语：我正在做比刷剧更重要的事

```

先跑一周，再根据「实际被拦了几次」调整时长——拦得太狠会让你想卸载，拦得太松等于没有。

## 7. 常见问题

**Q：开了屏蔽，但积分好像没涨？**
积分按分钟结算，需要浏览器保持运行（后台每分钟结算一次）。刚开启的头一分钟不计分，满一分钟才开始进账。如果长时间不涨，去 `chrome://extensions/` 对扩展点一次「重新加载」，再打开弹窗看「状态」页的数字是否变化；弹窗会显示具体错误原因，可点「重试」。

**Q：解除按钮一直是灰的？**
三种可能：① 冷静倒计时没走完（10 秒）；② 还在冷却期内（面板会显示还剩多久）；③ 开了严格模式（此时只能等结束或用通行证）。

**Q：为什么某个网站没被拦住？**
① 检查域名是否写对（要写主域名，如 `douyin.com`，不是完整网址）；② 确认「一键屏蔽」是开着的，或者定时规则正处于生效时段；③ 浏览器内部页面（`chrome://` 开头）、扩展商店页面不受任何扩展控制；④ 刚加进黑名单的那一瞬间，刷新一下页面再试。

**Q：能只屏蔽「短剧」这个分区吗？**
不能。拦截是**域名级**的，只能整体拦一个站点，无法识别站内某个标签页或某个内容类型。

**Q：定时屏蔽为什么解除不了？**
这是设计如此。定时规则代表长期习惯，提前解除只会暂停一个冷却周期，到点自动恢复。真想彻底停掉，去「定时」页把那条规则的开关关掉——但这一步需要你自己动手，不藏在「解除」按钮里。

**Q：通行证和护盾有什么区别？**
通行证是「合法逃生口」：豁免 30 分钟，不扣分、不清连胜、不进冷却，用掉就没了。护盾是「保连胜」的：只在提前解除时自动消耗，抵掉一次连胜清零，不会免掉扣分和冷却。

**Q：数据会丢吗？换电脑怎么办？**
数据存在浏览器本地 `chrome.storage.local`，卸载扩展或清理浏览器数据会一起清掉。去「规则」页底部「导出备份」存一份 JSON，换环境时导入即可恢复。

**Q：浏览器关着的时候计时吗？**
不计时也不需要计时——屏蔽会在你下次打开浏览器时按真实时间校正，到期的直接解除。屏蔽期间如果浏览器长时间关闭，恢复后按实际经过时长补算积分。

## 8. 数据与隐私

- 全部数据保存在本机浏览器，**不联网、不上传、无账号、无统计**
- 只申请三个权限：`storage`（存配置）、`declarativeNetRequest`（拦网页）、`alarms`（每分钟结算）
- 导出的 JSON 备份是明文，含黑名单和专注记录，分享前请自行检查

## 9. 已知限制

| 限制 | 说明 |
| --- | --- |
| 域名级拦截 | 无法只拦某个站内的短剧 / 推荐流分区 |
| 拦不住卸载 | 关掉或卸载扩展即可绕过，属浏览器扩展天花板 |
| 精度 ≤ 1 分钟 | 倒计时每秒刷新，但结算与自动起止依赖每分钟一次的闹钟 |
| 需浏览器在运行 | 关掉浏览器期间不产生积分 |
| 未上架商店 | 需要开发者模式手动加载 `dist` |

真想要更强的约束，只能配合系统级工具（如 hosts、屏幕时间），或者让信任的人代管扩展的开关权限。
